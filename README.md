# AfriTalent
Projet fil rouge — Plateforme de mise en relation entre freelances africains et
clients.
Auteur : Abdoul Aziz Ndoye
Promotion : L1 Web — ISI

AfriTalent est une plateforme dédiée à la valorisation des talents africains.
AfriTalent permet aux utilisateurs de présenter leurs compétences, découvrir de nouvelles opportunités et contribuer à la promotion de l'excellence africaine à l'échelle locale et internationale.
